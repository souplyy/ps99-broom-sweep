BROOM SWEEP MACRO (WINDOWS)

Extract the entire ZIP into a normal folder. The macro is PS99-Broom.ahk.
If Windows doesn't know how to open .ahk files, right-click that file, choose
Open with, select another app on this PC, and choose runtime\AutoHotkey64.exe
from this folder. Select the option to always use it for .ahk files if offered.
After that, double-click PS99-Broom.ahk. No separate downloads are required.
Keep the folder together and somewhere you have permission to edit files.

Open Roblox, stand in the same lobby position and camera orientation, and press F6
to start or stop. F8 closes the macro. Keep Roblox focused while it runs.

Click Update / reload to check for a published update and reopen the macro. If
offline or the check fails, the installed version reopens normally. The button
stops the active macro before updating. Diagnostics are
stored locally in masquerade/ and update-status.log; they are not uploaded.

This is an experimental visual macro. Screen size, UI scaling, camera angle and
game changes can affect detection. It has not been verified on another computer.
